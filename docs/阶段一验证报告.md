# 阶段一验证报告 — 核心管线

日期：2026-09-12
环境：macOS 27.0 / Apple Silicon / Swift 6.4（Command Line Tools，无完整 Xcode）
素材：ffmpeg 合成 4K HEVC（3840×2160、30fps、40Mbps、GOP 60、含 AAC 音轨）

## 一、技术关键点核对

### 5.2 无损直通（最高风险项）

`AVAssetReader` 与 `AVAssetWriter` 两端 `outputSettings` 均为 nil，未使用
`AVAssetExportSession`。结论：**比特级无损，不只是参数一致。**

视频码流逐包 MD5：

| | MD5 |
|---|---|
| 源文件 4.0–8.0s 片段 | `3ca95583367dfea770b4f6fb63e98254` |
| 本工具输出 | `3ca95583367dfea770b4f6fb63e98254` |

H.264 素材同样通过（`273763619d6e5454599fe95a00a29c7b`，源与输出一致）。

ffprobe 参数比对（源 → 输出）：codec `hevc`→`hevc`、tag `hvc1`→`hvc1`、
profile `Main`→`Main`、level `153`→`153`、`3840×2160`→`3840×2160`、
`yuv420p`→`yuv420p`、`30/1`→`30/1`。
唯一差异是容器 time_base `1/15360`→`1/600`，属容器重封装的正常结果，
30fps 在 600 时基下每帧 20 刻度，可整除，无时间漂移。

性能佐证：4 秒 4K 片段 0.52s 完成，35 秒 4K 片段 1.80s 完成（168MB 输出）。
这个速度本身就排除了重编码的可能。

### 5.1 Live Photo 配对三要素

| 要素 | 结果 |
|---|---|
| 封面 Maker Note 键 `"17"` | ✅ exiftool 读出 `[Apple] Content Identifier` |
| MOV `com.apple.quicktime.content.identifier` | ✅ exiftool 读出 `[Keys] Content Identifier` |
| MOV `com.apple.quicktime.still-image-time` 定时元数据轨 | ✅ Track3 / mebx / 1 sample |
| 两侧 UUID 一致 | ✅ |

静止帧时间点正确性：源时间轴封面帧 5.500s、裁剪起点吸附到 4.000s，
输出轨内读回 **1.500s** = 5.500 − 4.000。`AVAssetWriter` 按预期扣除了 session 起点。

### 5.4 帧精确抽帧

`requestedTimeToleranceBefore/After` 均设为 `.zero`。从 5.500s 起连抽 6 帧
（步长 1/30s），请求时间与实际返回时间**逐帧完全相等**，6 帧像素指纹互不相同。

## 三、附带验证的功能

- **模式徽标**：HEVC/H.264 → 无损直通；AV1(av01) → 需重编码，并给出原因文案。
- **裁剪吸附**：请求起点 5.000s → 实际 4.000s，界面如实报告「前移了 1.000 s」。
- **精确裁剪开关**：`--precise` 下起点精确落在 1.700s 不吸附，走重编码路径。
- **自动封面**：拉普拉斯方差在 24 个采样帧中选出最清晰帧并给出评分。
- **失败信息**：错误带阶段标签，如 `[抽帧] 无法抽取 1.200s 处的帧`。

## 四、已知限制与后续注意

1. **非 H.264/HEVC 编码不在支持范围内**（已与需求方确认，AV1 不做）。
   徽标会标出「需重编码」，但本机 AVFoundation 连 AV1 解码都不支持，
   实际表现为抽帧阶段报 `Cannot Open`。.webm 容器同样打不开。
2. **吸附会让片段变长**。当前实现保持终点不变，起点前移，所以请求 2s 可能得到 3.7s。
   这是 passthrough 的物理结果。阶段三时间轴需要把「实际生效区间」画出来，
   而不只是显示一个数字。
4. **CLI 的图库写入依赖 TCC**。二进制已嵌入 `__TEXT,__info_plist`
   （含 `NSPhotoLibraryAddUsageDescription`）并带 ad-hoc 签名，
   需在用户自己的 Terminal 中运行才能正常弹出授权窗口。
